# Documentation Index (Simplified)

This repository maintains a focused documentation set. Most legacy and
expanded materials have been archived to `.archive/deprecated/docs/`.

Recommended reading:
- `00_quick_start/` — minimal setup and first run
- `01_architecture/` — core architecture and pipeline overview
- `02_api_reference/` — public APIs
- `03_guides/` — short practical guides (developer setup, pipeline usage, security)

Everything else (status reports, critiques, deep dives, code reviews, etc.)
was archived. See `DEPRECATION_GUIDE.md` for where to find it.
