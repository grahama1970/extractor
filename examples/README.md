# Examples

This directory contains usage examples for the extractor library.

## Files

### Basic Examples
- **minimal_pdf_json_example.py** - Minimal example for PDF to JSON conversion
- **simple_pdf_extract.py** - Simple PDF extraction example
- **demonstrate_current_state.py** - Demonstrates the current working state of the extractor

### Comprehensive Examples
- **extractor_usage_function.py** - Comprehensive usage examples showing various features
- **comprehensive_usage_function.py** - Comprehensive usage patterns and features
- **final_comprehensive_usage.py** - Final comprehensive usage examples with all features

## Running Examples

Each example can be run directly:

```bash
python examples/minimal_pdf_json_example.py
```

Make sure you have activated your virtual environment and installed dependencies first:

```bash
source .venv/bin/activate
uv sync
```
