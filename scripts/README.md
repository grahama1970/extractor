# Scripts

This directory contains utility scripts for various purposes.

## Subdirectories

### debug/
Debugging and diagnostic tools:
- **debug_and_fix_extractor.py** - Debug section parsing issues
- **diagnose_extractor_import.py** - Troubleshoot import issues in other projects
- **fix_surya_dependencies.py** - Fix missing Surya model dependencies

### comparison/
Tools for comparing different extraction methods:
- **marker_extractor_comparison.py** - Compare original marker vs enhanced extractor
- **test_original_marker.py** - Test original marker functionality
- **use_original_marker_simple.py** - Simple wrapper for original marker
- **original_marker_isolated.py** - Isolated environment for original marker

### analysis/
Analysis and reporting scripts (to be added as needed)
