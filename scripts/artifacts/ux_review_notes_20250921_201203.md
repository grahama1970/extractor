# UX Review Notes (Tabbed Classic)

- **Scope**: Left rail thumbnails, bottom filmstrip, top toolbar/search tray.
- **Route**: `/main`
- **Files**: `src/components/ThumbnailRail.tsx`, `src/pages/ClassicLayout.tsx`, `src/components/ThumbnailStrip.tsx`, `src/components/SearchPanel.tsx`, `src/lib/pdf.ts`.

## Issues
- **Left rail**: thumbnails cropped at bottom.
- **Filmstrip**: cropped when `height < itemWidth*4/3`.
- **Toolbar**: search tray overlapped toolbar.

## Root causes
- Rail row height didn’t account for inner width + caption; width too tight in mount.
- Filmstrip height smaller than 3:4 for configured width.
- Search tray z-index above toolbar.

## Changes tried
- Rail: innerWidth height `round((width-16)*4/3) + 28`, object-contain frame, `shrink-0` rail.
- ClassicLayout: rail `width={200}`, sidebar `shrink-0`.
- Filmstrip: `effectiveHeight = max(height, itemWidth*4/3 + 16)`.
- SearchPanel: lowered z-index under toolbar.

## Minimal forward fix
- `ThumbnailRail.tsx`: change `+ 28` → `+ 36` (ThumbItem height).
- `ClassicLayout.tsx`: `<ThumbnailRail width={200}>` → `width={220}`.
- Optional: remove caption under thumb to guarantee headroom.

## Revert plan
Revert these files to last-known-good: `ThumbnailRail.tsx`, `ThumbnailStrip.tsx`, `SearchPanel.tsx`, `ClassicLayout.tsx`.

## Acceptance
- Left rail: no cropping at width=220; active ring visible; canvas not squeezed.
- Filmstrip: no cropping at itemWidth=100 (auto height guard).
- Toolbar: no overlap when search opens.
