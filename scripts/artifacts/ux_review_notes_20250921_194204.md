# UX Review Notes (Tabbed Classic)

- **Scope**: Left rail thumbnails, bottom filmstrip thumbnails, top toolbar and search tray docking.
- **Routes**: `/main` (Classic)
- **Primary files**:
  - `prototypes/tabbed/html/src/components/ThumbnailRail.tsx`
  - `prototypes/tabbed/html/src/pages/ClassicLayout.tsx`
  - `prototypes/tabbed/html/src/components/ThumbnailStrip.tsx`
  - `prototypes/tabbed/html/src/components/SearchPanel.tsx`
  - `prototypes/tabbed/html/src/lib/pdf.ts` (context: thumbnail render)

## What was wrong
- **Left rail thumbnails cropped** in some widths: bottom of the 3:4 frame clipped.
- **Bottom filmstrip thumbnails cropped**: wrapper height too short for the configured `itemWidth`.
- **Top toolbar overlap**: slide‑down Search tray visually overlaid toolbar contents.

## Root causes
- **[ThumbnailRail.tsx]** Row height used `width` directly without subtracting button padding and did not leave enough headroom for caption/padding.
- **[ClassicLayout.tsx]** Rail width (200) combined with caption/padding left too little vertical budget in virtualization row height.
- **[ThumbnailStrip.tsx]** `height` prop smaller than `itemWidth * 4/3`, guaranteeing crop.
- **[SearchPanel.tsx]** Higher z-index than toolbar.

## Changes attempted (by file)
- **ThumbnailRail.tsx**
  - Added innerWidth-based height: `height = round((width - 16) * 4/3) + 28`.
  - Frame is white 3:4 with `object-contain`; active ring clearer.
  - Rail container: `shrink-0`, vertical scroll.
- **ClassicLayout.tsx**
  - Pass explicit rail width (`width={200}`), left `Sidebar` set `shrink-0`.
  - Default thumb mode flipped briefly, then restored to `left`.
- **ThumbnailStrip.tsx**
  - Guard: `effectiveHeight = max(height, itemWidth*4/3 + 16)`; frame uses `object-contain`.
- **SearchPanel.tsx**
  - Lowered z-index so tray sits under toolbar (`z-0`).

## Current state
- Left rail uses innerWidth formula; still may be tight on some screens with caption. Two small constants fix it definitively:
  - Increase headroom: `+ 28 -> + 36` in `ThumbnailRail.tsx` (ThumbItem height).
  - Or bump width: in `ClassicLayout.tsx` `<ThumbnailRail width={200}>` -> `width={220}`.
- Bottom filmstrip no longer crops with default config (guard in place).
- Toolbar overlap addressed by `SearchPanel` z-index.

## Minimal forward fix (safe)
- **Option A (constants only)**
  - `ThumbnailRail.tsx`: `+28` -> `+36` in ThumbItem height.
  - `ClassicLayout.tsx`: rail `width={200}` -> `width={220}`.
- **Option B (remove caption)**
  - Remove the `P.{n}` caption div under the frame to recover ~20–24px.
