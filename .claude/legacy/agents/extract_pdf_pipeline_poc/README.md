# PDF Extraction Pipeline - Proof of Concept Experiments

This directory contains small, focused experiments to test each stage of the PDF extraction pipeline.

## Experiments:

1. `poc_01_marker_extraction.py` - Basic marker extraction
2. `poc_02_suspicious_headers.py` - Detect and fix suspicious headers
3. `poc_03_section_validation.py` - Validate sections with Claude
4. `poc_04_gold_comparison.py` - Compare results to gold standard

Each POC is self-contained and can be run independently.
