# Sanity Matrices (Index)

Contract Loop sanity checks are split into:

1. **Module-level checks**: `tools/contract_loop/docs/SANITY_MATRIX_CONTRACT.md`
2. **Project-level checks**: stored under each adapter, e.g.
   `tools/contract_loop/adapters/extractor/docs/SANITY_MATRIX.md`

Update the adapter matrix when adding or changing pipeline steps. Update the
contract matrix when changing the contract_loop harness itself.
