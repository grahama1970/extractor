# Contract Loop Scripts

Build + sanity helpers for the contract loop.

Clarify UI:
- `build_clarify_ui.sh`: build the React UI (outputs `clarify-ui/dist`).
- `clarify_ui_dev.sh`: dev server with hot reload.

Sanity checks:
- `sanity_contract_exec.py`: Codex exec harness smoke.
- `sanity_contract_bundle.py`: collaboration bundle guardrails.
- `sanity_contract_clarify.py`: clarifying UI/TUI smoke.
- `sanity_contract_auth.py`: Codex auth store preflight.
