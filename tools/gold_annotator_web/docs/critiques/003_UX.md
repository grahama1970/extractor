# 🎨 Color Schemes (Light + Dark)

A **neutral UI foundation** with **vivid but not overwhelming accent colors** for annotation types. These map to Shadcn/Tailwind tokens, ensuring accessibility (≥4.5:1 contrast).

### Base Neutrals

* **Light mode**

  * Background: `zinc-50`
  * Panel: `zinc-100`
  * Borders: `zinc-200`
  * Text: `zinc-800`

* **Dark mode**

  * Background: `zinc-900`
  * Panel: `zinc-800`
  * Borders: `zinc-700`
  * Text: `zinc-100`

### System States

* Primary: `indigo-500` (light), `indigo-400` (dark)
* Success: `emerald-500`
* Warning: `amber-500`
* Error: `rose-500`
* Info: `sky-500`

### Annotation Categories

Each label type has a **consistent accent color**:

* **Section** → `violet-500`
* **Table** → `emerald-500`
* **Figure** → `amber-500`
* **Requirement** → `sky-500`
* **Text note** → `rose-500`

> **Box styling rule:**
>
> * Border = 500 tone of accent
> * Hover fill = 100 tone (light) / 900 with opacity (dark)
> * Label badge = solid 500 background with white text
